# CDXML page-fit correction

The earlier CDXML export contained negative coordinates and no page or printer setup. ChemDraw inherited its last document/printer settings; the user reported a B4 document showing only a corner of the structure. Opening and saving the old default fixture through ChemDraw reproduced a two-page-wide drawing space (`1080 × 719.75 pt`). Native PNG export alone had concealed this issue because it crops to the artwork.

The corrected exporter fits a private graph copy uniformly within one US Letter page. Its printable drawing space is `540 × 720 pt`, inside 36-point paper margins. Nodes have positive coordinates, with additional room for labels and continuation waves. Page count, page bounds, fragment bounds and print geometry are explicit. Original MOL/SDF files retain their original coordinates. Boundary nodes remain `ExternalConnectionPoint/Wavy`, never element zero or invented carbon caps.

This uses the original ChemDraw SDK's documented [page counts](https://iupac.github.io/IUPAC-FAIRSpec/cdx_sdk/properties/WidthPages.htm), [drawing-space semantics](https://iupac.github.io/IUPAC-FAIRSpec/cdx_sdk/properties/DrawingSpaceType.htm), [print margins](https://iupac.github.io/IUPAC-FAIRSpec/cdx_sdk/properties/PrintMargins.htm), and [MacPrintInfo fields](https://iupac.github.io/IUPAC-FAIRSpec/cdx_sdk/properties/MacPrintInfo.htm). Despite its name, the latter controls paper geometry in the tested Windows ChemDraw application; the SDK documents `WinPrintInfo` as unused.

Seven actual hidden ChemDraw 23.1.2.7 cases passed: the default 108-atom source pore, 234-atom DMTP source pore, 240-atom automatic design, 232-atom four-connected source pore, isotope/tetrahedral/E and Z fixtures, and the optimized large-design export. ChemDraw reported one page, `540 × 720 pt`, and 100% magnification for every case. Native-saved fragment bounds and every node remained inside the page. All native PNGs had at least eight pixels of white border; the complete structures and boundary waves were visually inspected. Explicit atom, bond, hydrogen, charge, isotope and display tables survived the native CDXML save. Both small stereo fixtures also passed native MOL isomeric comparison.

The renderer may now pass its existing graph to the exporter. This fast path requires exact normalized serialization equality with the stored MOL and preserves literal unknown-double-bond marks. Mismatched graphs, defined stereochemistry and unsupported MOL variants fall back to the established parser. The measured 240-atom case took 0.029 seconds through this path versus 3.80 seconds through parsing; CDXML bytes were identical. The fast-path native PNG was also byte-identical to the independently viewed parser-path output.

The [portable native report](../benchmarks/cofdraw-chemdraw-page-fit.json) records all cases and hashes. Twenty-five focused export tests cover page bounds, widely translated/tiny drawings, unknown and defined stereo, boundary points, and supplied-graph mismatch handling. No physical printing or foreground application screenshot is claimed. Tests used isolated hidden documents and closed only the owned test instances. Large structures may require zoom for comfortable reading; this change addresses placement and clipping rather than layout cleanup. SVG presentation styles remain separate from editable chemical exports.

ChemDraw's own MOL save still drops external connection points. Preserve edited CDXML and the original COFdraw MOL/SDF plus graph metadata when continuation boundaries matter.

The rebuilt Windows executable was also checked separately: its exact 234-atom DMTP export opened and saved successfully in hidden native ChemDraw. The entire pore and all six continuation waves were visually inspected, with ten pixels of white border on every side. Native page bounds remained `540 × 720 pt`, one page, and explicit chemical tables matched. The [packaged-export report](../benchmarks/cofdraw-chemdraw-packaged-page-fit.json) binds the executable and unmodified input/output hashes.
