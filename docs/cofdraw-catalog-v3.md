# COFdraw catalog v3

The portable catalog contains 41 finite monomers with source-bound SMILES, readable full names, paper-specific abbreviations, functional-group counts, compatible drawing roles and qualified geometry hints. It preserves the four existing source recipe IDs and adds eight design starting pairs. The six-site triptycene/tetrahedral four-site pair is available for inspection only; it is not an executable planar preset.

All selected molecular evidence comes from the admitted **train** partition of inventory0031. The builder checks 94 annotation, crop and PDF file hashes, strict finite valences, the expected functional-group counts, and isomeric SMILES/MOL roundtrips. A separate smoke audit passed all 104 catalog monomer/implemented-linkage/role combinations. This validates the scoped graph conversion, not synthetic feasibility, crystallinity, periodic geometry or experimental topology. No model was used and no labels or source images were added.

Build with `scripts/build_cofdraw_catalog_v3.py`, supplying `--inventory`, `--source-catalog`, `--base-catalog` and a new `--output` directory. The script refuses to reuse an existing output directory. The packaged data are under `desktop-release-data-v2/framework-drawing`, with the catalog in `catalog-v3/catalog.json`; original v2 data remain unchanged. The bundle contains chemistry/layout JSON, source DOI/page/bbox/hash evidence and no PDF, source image, full extracted text or absolute private path.

The runtime registry is authoritative. The catalog's `compatible_roles` describes functional compatibility; the selected template must also accept site counts and geometry. `geometry_hint` is an idealized design aid, not a measurement. TAPM, TFPM and TFAPPM retain tetrahedral hints. Pyrene and porphyrin four-site examples have planar tetratopic hints. Six-site triptycene is explicitly nonplanar/unknown in this simple hint vocabulary. A count of four must never silently assign sql to a tetrahedral monomer.

Existing source presets retain their version-bound COFex notation and qualifications. New design presets keep `cofex_id`, source `cofex_notation`, and static `design_cofex_notation` null. The backend constructs a **design** notation from current monomers, the chosen net or `unk`, and explicitly assumed `cat0`. Editing a recipe does not preserve a literature identity. Even an expanded monomer-based COFex string is not a complete periodic atom graph and may not distinguish every linkage/PSM state.

The wider searchable taxonomy remains reference-only where no scoped transform exists: boronate ester, boroxine, imide, aminal, cyanovinylene, ketazine, dioxin, triazine, polyphenylene and several linkage conversions. Boronate formation is a cyclic B/O construction, boroxine is a three-site event, and imide requires a correctly adjacent carbonyl pair; none is represented by a generic single-bond connector. The subsequently added nitrone rule is narrowly scoped to the listed precursor roles; it does not implement the separate photo-rearrangement or identify a drawn template as COF-115.

The supplied local `A_COF retrosynthesis` folder was revisited for this update. `ChemXiom_Research_Plan.docx` (SHA `edbd804f8d731d988ea1bf9761c3de915838f03dee74af60438951cd8b3eb741`) separates molecular preparation, framework assembly, linkage conversion, pore-wall modification and condition-specific source attempts. It supports keeping those records distinct. The first three pages of the supplied *Covalent Chemistry beyond Molecules* perspective distinguish molecular bond construction from obtaining and retaining an ordered porous material. [Jiang, Zhao and Yaghi, 2016](https://doi.org/10.1021/jacs.5b10666). The abstract/introduction of the supplied monomer retrosynthesis study likewise separates access to monomers from their reticulation; its computational route findings do not certify arbitrary new material designs. [Chang and Rangarajan, 2026](https://doi.org/10.1021/acs.chemmater.6c00008). These were targeted planning reads, not new full-paper dataset reviews.

The [Yaghi publication index](https://yaghi.berkeley.edu/publications.html) was checked again on 17 November 2026. Targeted primary-paper checks reinforce two useful limits: nitrone COF construction uses hydroxylamine/aldehyde chemistry and retains the charged N–O functionality; its reported photo-rearrangement is a separate conversion. [Nitrone COF-115](https://yaghi.berkeley.edu/pdfPublications/23NitroneCOF.pdf). Oxidation of hydrazine-linked COFs produced partial hydrazide conversion in the examined examples, so a fully replaced ideal graph must not silently stand for measured occupancy. [Hydrazine–hydrazide COFs](https://yaghi.berkeley.edu/pdfPublications/22COFWater.pdf). The 2025 coumarin entry is a discovery lead already in the research catalog; its full article was not accessible in this update, and no new executable rule is claimed. Additional source links and prior review scope remain in `linkage-library-research.md` and `linkage-library-catalog.json`.
